# Study Cards App

Study Cards App - это веб-приложение для создания, управления и изучения карточек с иностранными словами, предназначенное для эффективного запоминания информации.

## 🚀 Функциональность

Раздел Learn: карточки для изучения с учетом статистики выученных слов

Раздел WordList: таблица со словами, загружаемыми по API, с возможностью добавления новых слов и редактирования слов

## 🛠️ Технологии

Frontend: React

Состояние: MobX

Стили: Sass

Данные: API

## 📦 Установка и запуск

#### Клонируем репозиторий
git clone https://github.com/DinaraDervel/study-cards-app.git

cd study-cards-app

#### Устанавливаем зависимости
npm install

#### Запускаем локальный сервер
npm run dev

## 📝 Использование

Открой приложение в браузере.

Выбери раздел Learn для изучения карточек или WordList для работы со списком слов.

В Learn можно изучать слова, а также отслеживать прогресс.

В WordList можно загружать слова по API, редактировать и добавлять новые.

Создай новые колоды и наполняй их словами для эффективного обучения.
